## Sensor Receiver Endpoint

The frontend reads sensor fallback data from `VITE_SENSOR_RECEIVER_URL`.

- Default: `/sensors.json`
- Dev behavior: Vite proxies `/sensors.json` to `http://localhost:8080/sensors.json`
- Backend-first mode: enabled by default (frontend tries `/api/dashboard/overview` first)

If you need a different endpoint, create a `.env` file in `frontend/`:

```env
VITE_SENSOR_RECEIVER_URL=http://localhost:8080/sensors.json
```

To force using the JSON receiver before the backend overview endpoint (useful for debugging):

```env
VITE_PREFER_SENSOR_RECEIVER=true
```
